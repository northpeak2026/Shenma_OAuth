# 神马直播第三方授权登录 Demo 完整需求

## 1. 项目说明与范围

### 1.1 项目目标

模拟第三方产品「神马体育」通过「神马直播」完成第三方授权登录的完整流程，覆盖 H5、App、桌面 Web，交互参考常见第三方授权登录体验。

### 1.2 项目定位

- 本项目是用于产品演示、需求评审及研发参考的独立前端 Demo。
- Demo里集成了H5、App、Web授权登录的三种场景，真实场景里需要根据用户的设备情况进行自适应。

## 2. H5 授权登录流程

1. 在神马体育登录页，展示「神马直播授权登录」入口（神马体育内部逻辑）。
2. 点击入口后，跳转神马直播 H5 授权页面。
3. 若神马直播未登录，先显示神马直播登录表单。用户提交正确的账号密码后，显示登录成功反馈并进入授权确认页；错误时停留在登录页并提示可重试。
4. 若已登录，跳过登录表单，直接进入授权确认页。
5. 授权页展示申请方神马体育的名称、图标、申请信息、当前神马直播账号信息以及「确认授权」「取消授权」。
6. 确认授权成功后，返回神马体育，并回传用户信息。
7. 取消授权、或授权失败后，返回神马体育登录页，并回传错误码。

## 3. App 授权登录流程

### 3.1 发起授权及正常唤起

1. 当用户安装了神马直播App时，点击授权后尝试唤起神马直播App。
2. 正常唤起时，进入神马直播 App 内页面。
3. 神马直播未登录时先展示登录表单；成功登录后进入授权确认，错误输入提示重试。
4. 神马直播已登录时，直接进入授权确认页。
5. 用户确认授权成功后返回神马体育，并回传用户信息。
6. 用户取消或授权失败时，返回神马体育登录页，并回传错误码。

### 3.2 无法唤起与 H5 兜底

1. 唤起App失败时，执行H5授权登录逻辑。

## 4. Web 授权登录流程

1. 在神马体育 Web 登录页，展示「神马直播授权登录」入口（神马体育内部逻辑）。
2. 点击入口后，跳转到神马直播 Web 授权页面。
3. 若神马直播未登录，先显示神马直播登录表单。用户提交正确的账号密码后，显示登录成功反馈并进入授权确认页；错误时停留在登录页并提示可重试。
4. 若已登录，跳过登录表单，直接进入授权确认页。
5. 授权页展示申请方神马体育的名称、图标、申请信息、当前神马直播账号信息以及「确认授权」「取消授权」。
6. 确认授权成功后，返回神马体育，并回传用户信息。
7. 取消授权、或授权失败后，返回神马体育登录页，并回传错误码。

## 5. 授权规则

### 5.1 授权信息与界面展示

| 信息 | 业务授权范围 | 页面是否展示 |
| --- | --- | --- |
| 用户 ID | 平台唯一ID，用于识别账号 | 不展示 |
| 昵称 | 用户昵称 | 展示 |
| 头像 | 用户头像 | 展示 |

### 5.2 授权前提与结果

- 未登录必须先完成登录；已登录可跳过表单，但不能跳过授权确认。
- 每次授权都必须由用户主动确认，不记忆过去的授权结果。
- 授权成功、失败、取消均返回发起方对应场景的神马体育页面。
